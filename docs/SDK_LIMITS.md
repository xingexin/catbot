# Agent SDK 接入与使用边界

本项目通过独立 Node 执行服务调用三家 Agent SDK，业务工具统一经过秘书的 MCP 接口。SDK 并非模型 API 协议；选择 `Key + Base URL` 直连时，上下文与工具循环由 Go 框架管理。

## 限制与恢复

- API 直连的“最大循环步数”限制模型调用轮数。Claude、CodeBuddy 使用 SDK 的 `maxTurns`。Codex SDK 当前未提供等价的轮数选项，因此只应用运行超时等边界；不声称它具有相同的步数限制，也不把并行工具数量当作轮数。
- 三家 SDK 原生会话按提供商隔离。相同配置和人格可恢复原生会话；切换策略或人格后，通过公共对话历史建立新的执行上下文，不跨 SDK 复用原生会话标识。
- 当前共享历史保存用户消息和最终回答，不能当作 SDK 原生过程日志的完整替代品。具体上下文压缩行为以框架配置及 SDK 自身能力为准。
- 宿主取消、运行超时、连接断开会触发 SDK 取消。取消是尽力终止，不能撤回已经发生的外部操作。
- 运行 ID 原子占用，重复提交不会盲目重新执行整轮。进程中断或发送结果未知时，应先检查运行和通知记录；不能承诺邮件或 QQ 外部副作用绝对执行一次。
- SDK 事件限制为单事件 1 MiB、整次运行累计 8 MiB、最多 10,000 个事件。超过限制明确失败，API Key 和 MCP 令牌不写入事件日志。
- 人格只影响表达与偏好；实际业务权限由服务端和插件授权检查。
- SDK 配置中的工具开关会原样保存，关闭后宿主不提供业务工具。当前 SDK 请求契约只接受文本；图片输入配置会明确报错。SDK 的流式及恢复能力由适配器提供，`maxTokens` 仅用于 API 直连，管理端不会把它作为 SDK 可调输出限制展示。
- Claude、CodeBuddy 通过 `tools: []`、已知原生工具禁用列表和 `canUseTool` 回调共同限制工具。根据 CodeBuddy iOA 实际初始化清单，已明确拒绝 PowerShell、REPL、SendMessage、系统调度、外部消息、文件及网络等内置能力；回调只允许合法的 `mcp__secretary__` 工具名，具体权限仍由秘书宿主检查。
- 不设置 `allowedTools`：两家 SDK 将其解释为自动批准权限，而不是排除其他工具的白名单，可能绕过权限回调。此处的拒绝列表与回调是 SDK 层防线，并非操作系统沙箱，也不承诺未知版本的所有原生行为均已隔离。升级 SDK 后需要重新检查初始化工具清单和两轮工具联调。

## 可复现检查

```sh
# 适配器、输入校验、运行 ID 去重等自动化测试，不调用真实模型
npm run test -w runtime

# 使用已保存在凭证库中的 CodeBuddy 配置，运行两轮真实模型调用
# 会创建名称带 [真实联调] 的人格、会话和运行记录；不会发送 QQ 消息
node scripts/codebuddy-smoke.mjs

# 一次真实模型工具调用创建约 90 秒后的 Temporal 提醒，结果仅保存到 Web
node scripts/codebuddy-task-smoke.mjs

# 视频处理：真实 FFmpeg，转写和视觉模型使用明确标注的本地替身
./scripts/video-media-smoke.sh
```

真实 CodeBuddy 测试默认访问 `http://127.0.0.1:5173`，使用配置 ID `codebuddy-ioa-glm53`。可通过 `TEST_BASE_URL` 和 `TEST_CODEBUDDY_CONFIG` 覆盖。脚本仅从现有配置引用服务端凭证，不读取或打印模型 Key。

## 视频模型前置条件

视频解析需要独立的 OpenAI 兼容转写 API 配置、转写模型名称，以及声明支持图片的 API 视觉配置。已验证的 CodeBuddy 文本 SDK 配置不能直接充当这两种配置。只有 fixture 配置时，不能据此声称真实音画解析已联调。

解析过程对音频每 20 分钟分段，最多抽取 20 帧并覆盖长视频全程。超过输入预算的转写会先分段摘要。模型必须返回有效的摘要、时间线和事项结构；失败时保留已完成的片段及“未完成”产物，避免把部分处理显示为完整解析。时间线来自抽样画面；音频没有逐字时间戳时不会承诺精确定位。
