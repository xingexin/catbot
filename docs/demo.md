# 演示场景

以下自然语言演示需要已联调的模型配置。确定性测试端点仅供 [验收脚本](acceptance.md) 检查接口，不能理解自由输入。

## 1. 同一工具跨策略使用

创建人格「办事秘书」，提示词写入「回答简洁；涉及实际操作时调用工具；明确说明操作是否成功」。启用示例插件并授予 `storage` 权限，将该人格绑定到会话。

输入：

> 用便签工具保存一条名为“面试准备”的便签：周末复习 Temporal 和 MCP。保存后再读取，告诉我读取到的内容。

分别在 API 与三种 SDK 会话中执行。查看「运行记录」中的策略、模型、人格快照、插件版本、工具输入输出和事件。切换策略时重新建立 SDK 上下文，插件业务代码保持一致。

可以讲清楚的设计：策略接口负责执行契约；API 分支自己处理工具循环；SDK 分支经 MCP 访问同一权限入口；人格无法绕过服务端授权。

## 2. 邮件摘要与定时管理

先配置测试邮箱和摘要模型，再从邮箱插件「每日邮箱摘要」模板创建周期任务：

- 时区：`Asia/Shanghai`。
- Cron：`0 9 * * *`。
- 步骤：`mail__summarize`，参数 `{"folder":"INBOX","limit":20,"unreadOnly":true}`。
- 选择结果通知对应的会话。

立即执行检查摘要产物，然后演示改期、暂停、恢复。停用邮箱插件后，依赖它的日程会暂停。重新启用插件后，在任务页明确恢复日程。

另用 `mail__sync` 演示增量游标；摘要工具读取最近匹配邮件，增量同步是独立工具。不要把两者混为同一个同步行为。

可以讲清楚的设计：统一的手动/定时任务入口、Temporal Schedule、UIDVALIDITY 与 UID、插件权限与凭证隔离、任务快照与调度意图恢复。

## 3. 视频解析后提取任务

配置转写模型与视觉模型，上传一段有语音的视频。在「文件与解析」创建解析任务，也可以用视频插件模板指定上传文件 ID。

任务第一步调用 `video__parse`。追加一个 Agent 步骤：

> 阅读前一步视频解析结果，列出事项及时间依据。只为含有明确未来日期、负责人为我、且要求提醒的事项创建任务；日期不明确时保留为待确认事项。

运行后展示：视频处理是独立插件；长任务走 Temporal；下一步取得上一步的结果；Agent 使用任务工具创建日程；解析产物与任务运行记录分别可查。

没有真实模型时，可以执行浏览器验收脚本，演示实际 FFmpeg 管道和结果保存，但应明确字幕与视觉结果来自固定测试响应。

## 4. 进程重启与不确定结果

执行 `node scripts/recovery-smoke.mjs`。脚本先完成第一步，在持久化 Timer 等待期间重启 backend，第二步在恢复后继续，并使用第一步结果。

展示 [恢复报告](../data/acceptance/recovery-report.json)。说明恢复边界是 Activity 完成结果；整轮 SDK 内部调用无法逐次回放。对于发送成功与否不明的外部操作，系统保留不确定状态，而不是盲目重发。
